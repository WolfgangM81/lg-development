# LicenseGuard Development - Repo Manager

Non-destructive migration wrapper for LicenseGuard multi-repo setup.

**Status:** 🚧 Under Construction

## Quick Start

```bash
# 1. Analyze dependencies
./scripts/analyze-dependencies.sh

# 2. Copy projects from monorepo
./scripts/copy-all.sh

# 3. Create GitHub repos
./scripts/create-github-repos.sh

# 4. Start migration
./scripts/migrate.sh
```
