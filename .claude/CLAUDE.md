# LG-Development - Claude Code Config

## Project Identity

**LG-Development** is a **Development Orchestrator** for the LicenseGuard multi-repo system.
It manages Docker Stack orchestration, package hot-reload, and multi-service development.

**Owner:** WolfgangM81 (GitHub)
**Stack:** TypeScript/Node.js, Docker Compose, Traefik, PostgreSQL, Redis, DynamoDB, Verdaccio
**Status:** Production Ready

## Critical Rules

### 1. NEVER run npm/node on the host

```bash
# CORRECT
docker run --rm -v $(pwd):/app -w /app node:20-alpine npm test
make test

# WRONG
npm install   # NEVER!
npm test      # NEVER!
```

### 2. repos/ are Git Clones (gitignored!)

- `repos/` contains clones from GitHub, NOT copies
- Never `git add repos/` in lg-development
- Each repo in `repos/` has its own `.git`
- Commit changes inside `repos/<service>/`, not in lg-development

### 3. Docker Compose is auto-generated

- `docker-compose.yml` is generated by `make prepare` / `collect-compose.py`
- Do NOT edit manually
- Regenerate with: `make collect`

## Quick Reference

```bash
# Daily Development
make start                   # Start Docker Stack
make stop                    # Stop all
make status                  # Health check
make logs SERVICE=user-service
make proxy-domains           # Setup/test proxy domains

# Hot-Reload (package dev)
make dev-sync                # Enable
make dev-sync-dashboard      # Monitor
make dev-normal              # Disable

# Testing (in Docker!)
make test                    # Sequential
make test-parallel           # Parallel

# Repo Management
./scripts/dev/setup.sh       # Clone repos from GitHub
./scripts/dev/update.sh      # Pull latest changes
```

## Proxy Domains

### With OrbStack (Port 80 - no port needed)
```
http://admin.lg.local/           → Admin UI
http://api.lg.local/user/health  → User Service
http://api.lg.local/keys/health  → API Keys Service
http://traefik.lg.local/         → Traefik Dashboard
```

### Universal (Port 8180 - works everywhere)
```
http://admin.lg.local:8180/
http://api.lg.local:8180/user/health
http://traefik.lg.local:8180/
```

### API Endpoints (via api.lg.local)

| Path | Service |
|------|---------|
| `/user/*` | User Service |
| `/permissions/*` | Permissions Service |
| `/rbac/*` | Permissions Service (RBAC) |
| `/keys/*` | API Keys Service |
| `/tour/*` | Tour Service |

## Service Architecture

| Service | Container | Port | Internal Route |
|---------|-----------|------|----------------|
| Admin UI | lg-frontend-admin | 3000 | `/` |
| User Service | lg-backend-user | 3002 | `/api/user` |
| Permissions | lg-backend-permissions | 3003 | `/api/permissions`, `/api/rbac` |
| API Keys | lg-backend-api-keys | 3001 | `/api/v1` |
| Tour Service | lg-backend-tour | 3004 | `/api/tour` |
| Menu Service | lg-backend-menu | 3005 | `/api/menu` |
| Secrets Service | lg-secrets-service | 3007 | `/api/secrets` |

**Infrastructure:** Traefik (80/8180), PostgreSQL (5432), Redis (6379), DynamoDB (8000), Verdaccio (4873)
